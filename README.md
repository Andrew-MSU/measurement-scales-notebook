# Measurement Scales in GIS: Nominal, Ordinal, Interval, Ratio

An interactive ArcGIS Notebook for GPHY 284 (Montana State University) that teaches the four measurement scales with Bozeman and Montana examples. Students classify attributes, see what is lost when ratio data is squashed into ordinal classes, and test why ratios of temperatures in °F are meaningless.

All data in the notebook is synthetic and illustrative.

## Use
Open `measurement_scales.ipynb` in ArcGIS Online Notebooks (the first cell connects with `GIS("home")`) or in Jupyter with the `arcgis` package, numpy, pandas, matplotlib and ipywidgets installed. Run the cells top to bottom.
